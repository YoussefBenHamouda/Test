# Ship It.

A minimal Express starting point for the **Ship It.** live workshop.

## Setup

```bash
git clone <your-repository-url>
cd ship-it-workshop
npm install
npm start
```

Open [http://localhost:3000](http://localhost:3000), then edit the placeholder text in `app.js` to make the page yours.

This repository is intentionally minimal for a live workshop: the Dockerfile and deployment approach are left for participants to build during the competition.
